
> ℹ️ Проект является одностраничным приложением (SPA). Весь код содержится в одном файле `index.html`.

---

## 🚀 Запуск проекта

### Локальный запуск

1. Скачайте файл **`index.html`**
2. Откройте его в любом современном браузере (Chrome, Firefox, Edge, Safari)
3. Всё готово! Приложение работает полностью локально.

### Публикация на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файл **`index.html`** (обязательно с таким именем)
3. В настройках репозитория включите GitHub Pages (Settings → Pages → Branch: `main`)
4. Сайт станет доступен по ссылке:  
   `https://ваш-username.github.io/имя-репозитория/`

## 💾 Хранение данных

Все данные сохраняются в **localStorage** браузера:

| Данные           | Ключ                         | Содержание                                      |
|------------------|------------------------------|-------------------------------------------------|
| Треки            | `life_music_tracks_v2`       | Массив объектов с аудио (Base64) и метаданными |
| Плейлисты        | `life_music_playlists_v2`    | Массив объектов с названиями и ID треков       |

> ⚠️ **Важно:** Лимит localStorage — около 5–10 МБ. Рекомендуемый размер файла до 8 МБ.

## ✨ Особенности проекта

- **Адаптивный дизайн** — корректно отображается на телефонах, планшетах и ПК
- **Тёмная тема** — приятная для глаз цветовая схема
- **Drag & Drop** — перетаскивание файлов для загрузки аудио и обложек
- **Работа без сервера** — приложение функционирует полностью в браузере
- **Чистый JavaScript** — без внешних зависимостей и фреймворков
